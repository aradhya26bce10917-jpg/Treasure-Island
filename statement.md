# Project Statement

## Problem Statement

Many beginner programming exercises focus on individual programming concepts without providing an interactive application. This project applies basic Python programming concepts by creating a text-based adventure game where the user's decisions control the flow of the game.

## Scope of the Project

The project focuses on creating a simple interactive adventure game using Python. The player makes choices at different stages, and the program displays different outcomes based on those choices.

## Target Users

- Students learning basic Python programming
- Beginners interested in text-based games
- Users who want to play a simple interactive adventure game

## High-Level Features

- Interactive player choices
- Multiple story paths
- Treasure-winning outcome
- Game-over outcomes
- Input-based decision making
