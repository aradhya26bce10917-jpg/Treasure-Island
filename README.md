Treasure Island 🏝️

# Overview

Treasure Island is a simple text-based adventure game developed using Python.

The player goes through different situations and makes choices at each stage. Depending on the choices made, the player either reaches the treasure or encounters a Game Over.

# Features

- Interactive text-based gameplay
- Multiple paths based on player choices
- User input using `input()`
- Conditional decision-making using `if`, `elif`, and `else`
- Different winning and losing outcomes
- Simple and beginner-friendly game interface

# Technologies Used

- Python
- Git
- GitHub

# How to Install and Run

1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Run `treasureislandaradhya.py`.
5. Follow the instructions displayed in the terminal.

# How to Play

The game presents different situations and asks the player to make choices.

For example:
- Choose `left` or `right`
- Choose `wait` or `swim`
- Choose between the available doors

Your choices determine what happens next.

# Testing

The game can be tested by running the Python program and trying different choices.

Test cases include:
- Choosing `left` at the crossroad
- Choosing `right` at the crossroad
- Choosing `wait` at the lake
- Choosing `swim` at the lake
- Choosing each available door
- Entering an invalid choice
